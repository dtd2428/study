# 정답·풀이 단축키 및 무응답 표시 설계

## 목적

문제 이동에는 `Alt + 방향키`가 있지만 정답·풀이 확인에는 단축키가 없어 키보드 중심 학습 흐름이 끊긴다. 연습 모드에서 `Alt + Enter`로 정답과 풀이를 확인할 수 있게 하고, 답안을 작성하지 않은 상태도 명확히 구분한다.

## 동작

- 연습 모드에서 `Alt + Enter`는 현재 문항의 정답·풀이를 표시한다.
- 답안이 없어도 풀이를 표시하며, 내 답안은 `미응답`으로 표시한다.
- 답안이 없는 현재 문항에는 답안 영역과 문제 탐색 번호에 미응답 상태를 표시한다.
- 모의고사 모드에서는 기존처럼 정답·풀이를 표시하지 않는다.
- 미응답 문항이 있어도 제출할 수 있고, 제출 확인 문구에서 미응답 개수를 알려준다.
- 화면 안내 문구에 `Alt + Enter` 단축키를 표시한다.

## 구현 경계

기존 `session.checked` 상태를 활용하고, 자동 채점·기록 데이터 구조는 변경하지 않는다. 미응답은 기존 답안 값이 빈 값인지를 기준으로 계산한다. 정답·풀이 표시와 제출은 각각 기존 UI 이벤트를 재사용한다.

## 검증

Playwright 테스트에서 답안 작성 후 단축키, 답안 없이 단축키, 무응답 표시, 무응답 포함 제출을 검증하고 기존 전체 테스트를 실행한다.
