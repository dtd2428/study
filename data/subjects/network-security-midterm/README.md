# 네트워크보안응용 중간고사

- 과목 ID: `network-security-midterm`
- 자료: 제공된 `네트워크보안_Lecture1-4_통합정리_빈칸학습.pdf` (34쪽)
- 범위: Lecture 1 통신·계층, Lecture 2 IP·전송, Lecture 3 라우팅·관리, Lecture 4 장비·VLAN
- 160문항: PDF 자가 점검 60문항을 웹 입력에 맞게 옮긴 `nsm-001`~`nsm-060`, 개념 응용 객관식 24문항과 서술형 16문항인 `nsm-061`~`nsm-100`, 쉬운 기초 확인 60문항인 `nsm-101`~`nsm-160`.
- 유형: 객관식 44, 단답형 61, 빈칸형 39, 서술형 16.

추가 기초 문제는 OSI 7계층 순서 쓰기와 계층별 이름, ARP(IP → MAC)·RARP(MAC → IP)·GARP, 주소 길이, TCP/UDP·응용 프로토콜, 라우팅 기초, 장비 이름과 VLAN을 짧게 묻습니다. 서술형 없이 객관식 20문항, 빈칸형 1문항과 단답형 39문항으로 구성했습니다. RARP는 과거 주소 설정 프로토콜이라는 조건을 명시했습니다.

`week` 1~4는 Lecture 1~4에 대응합니다. Lecture 3 라우터 관리 문항은 원본 복습 문제의 묶음과 관계없이 Lecture 3으로 분류했습니다.

모든 문항의 `source`는 **34쪽 통합 PDF의 페이지**를 가리킵니다. 원본 강의 슬라이드 페이지와 다릅니다. 추가 계산 문제는 `계산 응용`으로 표시했습니다. 원본 강의 슬라이드 자체를 추가 확인한 것은 아닙니다. PDF 파일은 사이트에 포함하지 않았습니다.

자료의 정정 사항(UDP 자체 제어 기능 부재, TCP 바이트 단위 순서번호, RIP 유효 15홉·16 도달 불가, EIGRP 고급 거리 벡터, Fragment-Free 앞 64바이트)을 반영했습니다. NAT 없는 전달 등 필요한 전제도 문제에 명시했습니다.

단답형에는 주요 한글·영문 표기를 허용합니다. O/X 6문항은 입력 대신 O·X 버튼으로 답합니다. 저장 형식은 기존 단답형을 유지하므로 예전 답안도 이어서 풀 수 있습니다. 빈칸형은 한 칸당 정답이 하나이므로 질문에 언어·숫자·표기 조건을 안내했습니다. 모든 칸을 맞혀야 한 문항이 정답입니다. 서술형은 모범답안과 평가 항목을 이용해 직접 평가합니다.

검증: `node tests/network-security.cjs`, `node tests/subjects.cjs`.

**주차·유형별 맞춤 학습 설정 → 문제 유형 → 기본개념문제**를 체크하면 `topics: ['basic']`으로 표시한 `nsm-101`~`nsm-160`만 출제합니다. 주차 및 답안 유형과 교집합으로 적용합니다. 위쪽 문제풀기 버튼도 필터를 적용하며 최대 30문항을 뽑습니다. 맞춤 학습에서 출제 문항 수를 선택 범위 전체로 지정하면 60문항을 모두 풀 수 있습니다.

Lecture 1 기초 객관식은 `nsm-141`~`nsm-160`의 20문항입니다. 기본개념문제를 체크하고 1주차·4지선다만 선택하면 이 20문항만 출제합니다.
