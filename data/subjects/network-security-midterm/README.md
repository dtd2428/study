# 네트워크보안응용 중간고사

- 과목 ID: `network-security-midterm`
- 자료: 제공된 `네트워크보안_Lecture1-4_통합정리_빈칸학습.pdf` (34쪽)
- 범위: Lecture 1 통신·계층, Lecture 2 IP·전송, Lecture 3 라우팅·관리, Lecture 4 장비·VLAN
- 184문항: PDF 자가 점검 60문항을 웹 입력에 맞게 옮긴 `nsm-001`~`nsm-060`, 개념 응용 객관식 24문항과 서술형 16문항인 `nsm-061`~`nsm-100`, 쉬운 기초 확인 84문항인 `nsm-101`~`nsm-184`.
- 유형: 객관식 58, 단답형 67, 빈칸형 43, 서술형 16.

추가 기초 문제는 OSI 7계층 순서 쓰기와 계층별 이름, ARP(IP → MAC)·RARP(MAC → IP)·GARP, 주소 길이, TCP/UDP·응용 프로토콜, 라우팅 기초, 장비 이름과 VLAN을 짧게 묻습니다. 서술형 없이 객관식 34문항, 빈칸형 5문항과 단답형 45문항으로 구성했습니다. RARP는 과거 주소 설정 프로토콜이라는 조건을 명시했습니다.

`week` 1~4는 Lecture 1~4에 대응합니다. Lecture 3 라우터 관리 문항은 원본 복습 문제의 묶음과 관계없이 Lecture 3으로 분류했습니다.

모든 문항의 `source`는 **34쪽 통합 PDF의 페이지**를 가리킵니다. 원본 강의 슬라이드 페이지와 다릅니다. 추가 계산 문제는 `계산 응용`으로 표시했습니다. 원본 강의 슬라이드 자체를 추가 확인한 것은 아닙니다. PDF 파일은 사이트에 포함하지 않았습니다.

자료의 정정 사항(UDP 자체 제어 기능 부재, TCP 바이트 단위 순서번호, RIP 유효 15홉·16 도달 불가, EIGRP 고급 거리 벡터, Fragment-Free 앞 64바이트)을 반영했습니다. NAT 없는 전달 등 필요한 전제도 문제에 명시했습니다.

단답형에는 주요 한글·영문 표기를 허용합니다. O/X 6문항은 입력 대신 O·X 버튼으로 답합니다. 저장 형식은 기존 단답형을 유지하므로 예전 답안도 이어서 풀 수 있습니다. 빈칸형은 기본 정답과 필요에 따라 추가 허용 답안을 지정하며, 질문에 언어·숫자·표기 조건을 안내했습니다. 모든 칸을 맞혀야 한 문항이 정답입니다. 서술형은 모범답안과 평가 항목을 이용해 직접 평가합니다.

검증: `node tests/network-security.cjs`, `node tests/subjects.cjs`.

**주차·유형별 맞춤 학습 설정 → 문제 유형 → 기본개념문제**를 체크하면 `topics: ['basic']`으로 표시한 `nsm-101`~`nsm-184`만 출제합니다. 주차 및 답안 유형과 교집합으로 적용합니다. 위쪽 문제풀기 버튼도 필터를 적용하며 최대 30문항을 뽑습니다. 맞춤 학습에서 출제 문항 수를 선택 범위 전체로 지정하면 84문항을 모두 풀 수 있습니다.

Lecture 1 기초 객관식은 `nsm-141`~`nsm-174`의 34문항입니다. 기본개념문제를 체크하고 1주차·4지선다만 선택하면 이 34문항만 출제합니다.

`nsm-161`~`nsm-184`는 OSI 1~7계층의 단위와 기능을 함께 묻는 24문항(객관식 14, 단답형 6, 빈칸형 4)입니다. 물리의 비트, 링크의 프레임, IP 패킷, TCP 세그먼트, UDP 데이터그램을 구분합니다. 세션·표현·응용은 자료에 맞춰 데이터·메시지로 표현하며 대화 관리·형식 변환·서비스 제공이라는 역할로 구분합니다.

계층을 식별하는 문제는 번호 대신 한글 계층 이름으로 답하도록 구성했습니다. 빈칸에는 문제 안내에 따라 “계층”을 빼고 이름만 씁니다. 번호를 보고 이름을 쓰는 문제와 계층 순서 쓰기는 유지합니다.

알고리즘 비교 빈칸 `nsm-045`는 `answerAliases`로 벨만포드·벨만 포드·Bellman-Ford와 다익스트라·Dijkstra 등 한글·영문 표기를 함께 정답으로 인정합니다. 이 칸들은 띄어 쓴 이름도 허용합니다. 검증: `node tests/blank-aliases.cjs`.

객관식 58문항의 오답 보기 174개에 개별 설명을 작성했습니다. 보기의 `explanation`에 보존하므로 보기 순서를 섞거나 JSON으로 내보내도 설명이 해당 보기 ID와 함께 유지됩니다. 선택한 오답의 설명은 정답 확인 및 결과·기록 화면에서 표시합니다.
