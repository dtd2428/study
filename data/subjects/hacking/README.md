# 해킹실무

- 과목 ID: `hacking` (기존 기록과 연결되므로 유지)
- 범위: 1~7주차
- 문제: 239문항 (4지선다 58, 단답형 89, 빈칸 11, 서술형 81)
- 문제 파일: `questions.js`
- 출처: 제공된 해킹실무 1~7주차 통합정리 빈칸학습 PDF, 35쪽 / SUID 관련 ppt.pdf, 13쪽

문제 ID `hk-001`~`hk-092`와 정답 보기 ID는 구조 정리 전과 동일합니다.
`hk-093`~`hk-097`은 SUID 실습 다섯 사례의 단답형입니다. 호출 전 RUID·EUID, 호출 후 RUID·EUID를 숫자 네 개로 입력합니다. 공백 또는 쉼표로 구분하며, 7주차 단답형 출제 범위에 포함됩니다. 성공·실패 표기는 PPT의 구분을 따릅니다.
원본 PDF는 저장소에 포함하지 않습니다. 다른 과목은 이 폴더에 섞지 않고 옆에 별도 폴더를 만듭니다.

## 친구 제공 문제

`hk-friend-*` ID의 142문항을 기존 과목에 추가했습니다. 원문 주차별 135문항 + 5단계 서술형 6문항 + 실전 예상 고유 객관식 1문항이며, 실전 예상의 중복 13문항은 통합했습니다. 기존 97문항은 유지합니다.

- 출처: 친구 제공 「해킹실무 문제풀이 전체소스코드」 HTML 내 JSON 데이터.
- 추가 유형: 단답형 63, 빈칸형 5, 서술형 73, 객관식 1.
- 설명형·여러 예시 답안은 문장 완전 일치 오채점을 피하기 위해 서술형 직접 평가를 사용합니다.
- 실습 조건·코드는 문제 본문에 포함하고 힌트·강의 기준 주의 사항은 해설에 보존했습니다.
- 원문의 성공·실패는 강의 목표 달성 표기이며 setuid 함수 반환값과 구분합니다. 원문 쪽수는 기존 통합 PDF 쪽수와 다릅니다.

다섯 SUID 사례의 15문항(기존 빈칸 5개·PPT 단답 5개·친구 빈칸 5개)은 `practice` 조건 데이터로 터미널 형태의 실습 패널을 표시합니다. 권한 문자열(`-rwxr-xr-x` / `-rwsr-xr-x`), 소유자, 실행 계정과 UID, 실행 명령, setuid 호출값, 강의 기준 성공·실패를 문제에 공개합니다. 호출 전후 RUID·EUID 네 값은 빈칸으로 남깁니다. 친구 문제의 성공·실패 입력칸은 조건에 공개하므로 제거했습니다. 파일 크기·날짜·그룹 소유권은 추가로 가정하지 않습니다. 나머지 래퍼 빈칸 1개는 기존 텍스트 조건을 유지합니다.
